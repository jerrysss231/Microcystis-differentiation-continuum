# Input data

The analysis scripts expect input files under a local `data/` directory. Large genome alignments, NCBI assemblies, external reference databases and climate rasters are not stored in this repository.

A typical layout is:

```text
data/
├── metadata/
│   ├── Microcystis_final_metadata.xlsx
│   └── Microcystis_final_metadata_with_clade.xlsx
├── snp/
│   ├── gubbins.filtered_polymorphic_sites.fasta
│   └── core_alignment_final.fasta.vcf
├── ani/
│   └── fastani_all_vs_all.txt.matrix
├── recombination/
│   ├── gubbins.recombination_predictions.gff
│   └── Gubbins_Recombination_Stats_140.xlsx
├── trees/
│   ├── SpeciesTree_final.treefile
│   ├── gubbins.final_tree_pruned.tre
│   └── gtdb_rooted_tree.treefile
├── climate/
│   └── wc2.1_2.5m_bioc_MPI-ESM1-2-HR_ssp245_2041-2060.tif
└── ...
```

The PopGenome workflow uses `core_alignment_final.fasta.vcf` together with the C1-C5 assignments generated by `analysis/population_structure/population_structure_ani.R`.

Some analyses also use derived files produced by earlier steps. For example, the differentiation-continuum analysis reads a pairwise summary table containing FST, Dxy, ANI distance, gene-content distance and gene-flow estimates, and the Gradient Forest analysis reads LFMM2 outputs generated by the genotype-environment association workflow.

Set `MICROCYSTIS_PROJECT_ROOT` to the directory containing the local `data/` and `results/` folders before running the scripts. File names can be changed directly in a script when reproducing the workflow with a different local organization.

Genome accession information and article-associated derived data should be obtained from the data availability resources accompanying the study.
